    // Comprobación básica; no reconstruye la sesión si el Agent se reinicia.

        ros.info("Se perdio la conexion WiFi");

PRUEBA EN EL COMPUTADOR
En cada terminal, cargue el entorno ROS 2 y configure el dominio elegido:
    source /opt/ros/humble/setup.bash
    export ROS_DOMAIN_ID=13

Con el paquete del Agent disponible, iniciarlo antes de arrancar el ESP32:
    ros2 run micro_ros_agent micro_ros_agent udp4 --port 8888

En otra terminal:
    ros2 node list
    ros2 topic list -t

Si habilitó los ejemplos anteriores, observar la salida:
    ros2 topic echo /salida

Desde otra terminal, enviar la entrada:
    ros2 topic pub --once /entrada std_msgs/msg/Bool "{data: true}"

Compile y cargue desde PlatformIO IDE en VS Code: Build -> Upload -> Monitor.
